PUT ALL YOUR SCREENSHOTS AND PHOTOS IN THIS FOLDER.

NAMING RULE
  <system id>-1.jpg   the cover image (shows on the card and the top of the project page)
  <system id>-2.jpg   more screenshots
  <system id>-3.jpg   ...

  Example: for a system with id "inventory-app" use
    inventory-app-1.jpg
    inventory-app-2.jpg

  Use only lowercase letters, numbers and dashes. No spaces.
  Your photo (optional) can be photo.jpg.

IDEAL SIZE
  1600 x 1000 pixels (a wide 16:10 shape), JPG or WebP, under 300 KB each.
  Free tool to shrink and convert images: https://squoosh.app

Then list the files in content.js, in the "screenshots" line of that system.
If a file is missing, the site shows a quiet placeholder frame instead of a broken picture.
While you preview on your own computer that frame is labelled "[ADD SCREENSHOT]";
visitors never see the label.
