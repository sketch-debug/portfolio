DOWNLOADABLE FILES LIVE HERE.

Jeffrey-Valeros-Resume.pdf is the resume the "Download resume" button serves,
on the home page and on the About page.

HOW TO CHANGE THE RESUME

1. Edit the words in resume.html (it is a plain web page, but sized for A4).
2. Open resume.html in Chrome and press Ctrl + P (Cmd + P on a Mac).
3. Choose "Save as PDF", paper size A4, margins "Default", and save it over
   files/Jeffrey-Valeros-Resume.pdf. Keep the file name exactly the same, or
   update resumeUrl in content.js to match.
4. If you later design your resume in Word or Google Docs instead, export it as
   a PDF, drop it in this folder, and point resumeUrl at that file. Nothing else
   needs to change.

Only put the PDF here, never the source document: everything in this folder is
published to the internet when you push.
