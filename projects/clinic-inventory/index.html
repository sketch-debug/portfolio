Clinic Stock Ledger

An append-only stock ledger for a clinic, built as a macro-enabled Excel workbook that staff already know how to use.

Source on GitHub
RoleSolo
TimelineOct 2026
TypeDesktop

At a glance

The problem

Stock disappears into edited spreadsheets: there is no audit trail, and a wrong cell is impossible to trace.

What I built

A workbook where stock is never typed. Every movement is a new row in a Log, and the Items sheet derives current stock with SUMIFS.

Key features

01

Append-only log

Mistakes are fixed with a reversal row, never by editing or deleting history.

02

Guards before writing

A reversal must name the row it undoes, cannot exceed it, and cannot take an item below zero.

03

One source of truth for the layout

Sheet names, columns and anchors live in one Python file; the VBA constants are generated from it.

04

Drift check

A script fails the build if the workbook, the VBA and the layout disagree.

05

Tests against the real macros

The test script drives the actual macros on a scratch copy and asserts zero formula errors.

Decisions and trade-offs

The trade-off

Two copies of the truth: the workbook builder and the VBA both described the layout.

What I did

Moved the layout into one Python module and generated the VBA constants from it, with a check that fails on drift.

The trade-off

A spreadsheet invites silent edits to past numbers.

What I did

Made the ledger append-only, with reversal rows and validation that refuses a bad movement before anything is written.
