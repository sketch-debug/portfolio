03 / Desktop

Secure Review

A command-line tool that runs Checkov, Trivy and Bandit over a codebase and returns one normalized, prioritized SARIF report.

TypeDesktop

At a glance

The problem

Three scanners each answer in their own shape, with their own severities, so nobody can tell what actually needs fixing first.

What I built

A CLI that runs Checkov, Trivy config and Bandit, normalizes their findings into one severity order, and writes SARIF for code scanning.

Key features

01

One report, one severity order

Findings from three scanners are normalized and ranked together.

02

SARIF output

The result drops straight into a code-scanning view.

03

Honest failure states

A scanner that never ran is reported as a tool error, not as a clean pass.

04

Reproducible fixtures

Real Checkov and Trivy output is committed and asserted, so an upgrade cannot quietly produce a false green.

05

Pinned upgrades

Scanner versions are pinned in six places; one script moves the mechanical pins and refuses to guess the rest.

Decisions and trade-offs

The trade-off

An old scanner reading new fixtures, or the reverse, gives a green build that means nothing.

What I did

Committed verbatim scanner output as fixtures, with provenance assertions on the embedded version.

The trade-off

Silent severity mismatches between tools.

What I did

Normalized every finding into a single ordering before reporting.

The trade-off

A scanner that crashes is easy to mistake for a scanner that found nothing.

What I did

Reported a tool that never ran as an error state, so a broken run can never be read as a pass.
