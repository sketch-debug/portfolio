Endpoint Threat Tracker

A defensive, read-only threat detection and incident tracker for Windows endpoints, with a local dashboard.

TypeWeb

At a glance

The problem

A small team has endpoint logs and indicator lists, but nothing that turns them into incidents someone can work through.

What I built

Export scripts drop metadata-only logs into an inbox; the tracker parses them, scores machines against editable indicators, correlates signals into incidents, and tracks response to a 14-day re-check.

Key features

01

Read-only by construction

It only reads files dropped into an inbox folder: it never scans, probes, blocks or deletes on any machine.

02

Detection families

Cryptomining, ransomware, remote access and suspicious-execution rules, all editable as indicator lists.

03

Incidents with checklists

Correlated signals become incidents with per-type response checklists, per-PC workflow states and a post-cleanup re-check.

04

Config, not code

Every path, threshold, weight and indicator list is a config file, so tuning needs no code change.

05

Hardened parsing

Event logs arrive as CSV with a JSON column, so XML-based parser attacks have no surface.

06

Audit and alerts

Parameterised SQLite storage with schema tracking, PBKDF2 sessions, and alerts to log, email or Teams.

Decisions and trade-offs

The trade-off

Security tooling that scans endpoints is itself a risk: a bug becomes an outage on someone else's machine.

What I did

Constrained it to read-only ingest from a drop folder, and wrote that boundary down as the first design rule rather than a feature.

The trade-off

The parser was the soft spot. XML-based event logs open the door to entity-expansion attacks.

What I did

Removed XML entirely: logs are exported as CSV with a JSON column, which closes that class of attack instead of filtering it.

The trade-off

Scoring rules change every week, and a code change per rule means a deploy per rule.

What I did

Every path, threshold, weight and indicator list lives in config, so tuning happens without touching the tracker.
